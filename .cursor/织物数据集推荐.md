# 布匹织物分类数据集推荐

## 推荐的公开数据集

### 1. TextileNet（最推荐）⭐⭐⭐⭐⭐

**特点**：
- **规模最大**：约 76 万张图片
- **类别丰富**：33 种纤维类型 + 27 种织物类型
- **用途广泛**：适合材料分类、织物纹理识别

**下载链接**：
- 论文：https://arxiv.org/abs/2301.06160
- 数据集：通常在论文中提供下载链接

**适用场景**：
- 织物类型分类（棉、麻、丝、化纤等）
- 织物纹理识别（平纹、斜纹、缎纹等）
- 材料成分识别

---

### 2. Fabric Image Data (FID) ⭐⭐⭐

**特点**：
- **规模**：12,181 张羊毛织物图片
- **分辨率**：约 420×570 像素
- **类别**：4 类（lattice、pattern、solid、stripe）

**下载链接**：
- GitHub：https://github.com/rhrobot/Fabric-Image-Data

**适用场景**：
- 织物图案分类（格子、图案、纯色、条纹）
- 适合作为入门数据集

---

### 3. CottonFabricImageBD ⭐⭐⭐⭐

**特点**：
- **规模**：1,300 张原始图片，增强后约 27,300 张
- **类别**：13 类（按棉含量 30%-99% 分类）
- **用途**：预测棉含量百分比

**下载链接**：
- PubMed：https://pubmed.ncbi.nlm.nih.gov/39081491/

**适用场景**：
- 织物成分百分比预测
- 回收分类
- 质量分级

---

### 4. Fabric Defect Dataset（织物缺陷数据集）⭐⭐⭐⭐

**特点**：
- **规模**：2,468 张图片
- **类别**：6 种缺陷类型（broken button、hole、color-defect 等）
- **标注**：包含边界框标注

**下载链接**：
- Mendeley Data：https://data.mendeley.com/datasets/y62b4pfyz2/1

**适用场景**：
- 织物缺陷检测
- 质量控制系统
- 工业检测

---

### 5. WFDD (Woven Fabric Defect Detection) ⭐⭐⭐⭐

**特点**：
- **规模**：4,101 张机织织物图片
- **标注**：像素级标注
- **用途**：缺陷检测和定位

**下载链接**：
- Papers with Code：https://paperswithcode.com/dataset/wfdd

**适用场景**：
- 缺陷分割
- 异常检测
- 纹理背景分类

---

### 6. TeXMET（大都会博物馆纺织品数据集）⭐⭐⭐

**特点**：
- **规模**：1,697 个纺织品对象，约 18,644 张高清图片
- **特点**：历史纺织品、挂毯
- **元数据**：包含风格、地区、时期等信息

**下载链接**：
- Hugging Face：https://huggingface.co/datasets/hzafar/TEXMET

**适用场景**：
- 历史纺织品识别
- 风格分类
- 文化遗产研究

---

## 如何选择数据集？

### 根据任务选择：

| 任务类型 | 推荐数据集 | 原因 |
|---------|-----------|------|
| **织物类型分类** | TextileNet | 类别最全，数据量最大 |
| **图案分类** | Fabric Image Data | 简单清晰，适合入门 |
| **成分预测** | CottonFabricImageBD | 专门针对成分百分比 |
| **缺陷检测** | Fabric Defect Dataset, WFDD | 专门用于缺陷检测 |
| **历史/风格分类** | TeXMET | 包含丰富的元数据 |

                with open(self.dataset_zip_path, 'wb') as f:
                    for chunk in r.iter_content(chunk_size=8192):
                        f.write(chunk)
            print("Download complete.")
    
    def extract_and_organize(self):
        # 解压和整理逻辑
        # 根据具体数据集的格式来实现
        pass
    
    def get_dataset(self):
        if os.path.exists(self.organized_images_dir):
            print("Dataset already exists. Returning the root directory.")
            return self.organized_images_dir

elif args.dataset == 'textile_net':

## 注意事项

1. **数据量**：TextileNet 数据量很大（76万张），需要足够的存储空间
2. **类别数量**：根据实际需求选择子集，不一定需要所有类别
3. **数据增强**：织物图片可能需要特定的数据增强（旋转、翻转等）
4. **预处理**：某些数据集可能需要预处理（裁剪、归一化等）

---

## 推荐的学习路径

1. **入门**：从 Fabric Image Data 开始（4 类，数据量小）
2. **进阶**：使用 TextileNet 的子集（选择 10-20 个常见类别）
3. **专业**：使用完整的 TextileNet 或针对特定任务的数据集
