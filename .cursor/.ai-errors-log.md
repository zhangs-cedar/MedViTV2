## 🧠 错误模式库

### PATTERN-001: 路径拼接错误
- **特征**: 使用 `+ '\\'` 或 `+ '/'` 拼接路径
- **修正**: 使用 `os.path.join(base, sub, file)`
- **示例**:
  ```python
  # ❌ 错误
  path = base_dir + '\\' + filename
  # ✅ 正确
  path = os.path.join(base_dir, filename)
  ```
