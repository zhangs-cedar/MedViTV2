## 🎯 项目概述

### 项目名称
MedViTV2 (Medical Vision Transformer V2)

### 项目目标
MedViTV2是一个用于医学图像分类的Vision Transformer模型，主要特点包括：
- 集成Kolmogorov-Arnold Network (KAN)层到Transformer架构中，提高模型表达能力
- 使用Dilated Neighborhood Attention (DiNA)机制，扩展感受野并缓解特征崩溃
- 采用分层混合策略，通过LFP (Local Feature Perception) 和 GFP (Global Feature Perception) 块平衡局部和全局特征感知
- 在17个分类数据集和12个损坏数据集上实现最先进的性能
- 相比MedViTV1，效率提升44%，准确率提升4.6% (MedMNIST)、5.8% (NonMNIST)、13.4% (MedMNIST-C)

### 技术栈
- **深度学习框架**: PyTorch 2.5.0, torchvision 0.20.0
- **模型库**: timm (PyTorch Image Models)
- **医学数据集**: medmnist 3.0.2
- **注意力机制**: natten 0.17.3 (Neighborhood Attention)
- **数据处理**: einops, torchvision.transforms
- **其他依赖**: numpy, pandas, scikit-learn, grad-cam, tqdm

## 🏗️ 架构设计

### 整体架构
```
输入图像 (B, 3, 224, 224)
    ↓
Stem层 (4层ConvBNReLU)
    ↓
Stage 1: [LFP × depths[0]]
    ↓
Stage 2: [LFP × (depths[1]-1), GFP × 1]
    ↓
Stage 3: [LFP, LFP, GFP] × (depths[2]//3)
    ↓
Stage 4: [GFP × depths[3]]
    ↓
BatchNorm2d
    ↓
AdaptiveAvgPool2d(1, 1)
    ↓
分类头 (Linear)
    ↓
输出logits (B, num_classes)
```

**架构层次**:
1. **Stem层**: 初始特征提取，将输入图像从3通道转换为64通道特征图
2. **特征提取阶段**: 4个Stage，每个Stage包含多个LFP或GFP块，逐步提取和融合特征
3. **分类头**: 全局池化后通过线性层输出类别预测

### 架构原则
- **模块化**: 高内聚低耦合，LFP和GFP块独立设计，可灵活组合
- **分层设计**: 
  - 底层使用LFP块捕获局部特征（Neighborhood Attention）
  - 高层使用GFP块捕获全局特征（Efficient Multi-Head Self-Attention + KAN）
  - 渐进式混合策略：早期Stage以LFP为主，后期Stage以GFP为主
- **依赖管理**: 
  - 核心模型定义在`MedViT.py`
  - 数据集处理在`datasets.py`
  - KAN实现独立在`fasterkan.py`
  - 训练逻辑在`main.py`

### 核心模块
1. **LFP (Local Feature Perception)**: 局部特征感知块
   - 使用Neighborhood Attention捕获局部邻域信息
   - 配合LocalityFeedForward进行局部特征变换
   - 适用于早期特征提取阶段

2. **GFP (Global Feature Perception)**: 全局特征感知块
   - 结合Efficient Multi-Head Self-Attention (E_MHSA) 和 Multi-Head Convolutional Attention (MHCA)
   - 使用KAN层替代传统MLP进行特征变换
   - 适用于高级语义特征提取

3. **KAN (Kolmogorov-Arnold Network)**: 可学习的激活函数网络
   - 使用ReflectionalSwitchFunction作为基函数
   - 通过可学习的样条函数实现非线性变换
   - 在GFP块中替代传统MLP，提高表达能力

4. **Neighborhood Attention**: 邻域注意力机制
   - 来自natten库，实现高效的局部注意力
   - 通过kernel_size控制感受野大小
   - 在LFP块中使用，降低计算复杂度

## 🔄 业务流程

### 主要流程
```
1. 参数解析 (argparse)
   ↓
2. 数据集构建 (build_dataset)
   - 判断数据集类型（MedMNIST或其他）
   - 下载/加载数据集
   - 应用数据增强
   ↓
3. 模型初始化
   - 选择模型变体（tiny/small/base/large）
   - 加载预训练权重（可选）
   - 移动到GPU
   ↓
4. 优化器和调度器设置
   - AdamW优化器
   - CosineAnnealingLR学习率调度器
   ↓
5. 训练循环（每个epoch）
   - 训练阶段：前向传播 → 损失计算 → 反向传播 → 参数更新
   - 验证阶段：前向传播 → 指标计算 → 模型保存（如果最佳）
   ↓
6. 保存最佳模型
```

### 关键步骤
1. **数据准备**: 
   - MedMNIST数据集：使用medmnist库自动下载和加载
   - 自定义数据集：通过下载器类下载、解压和组织数据
   - 数据增强：训练时使用RandomResizedCrop、AugMix、RandomHorizontalFlip等

2. **模型训练**: 
   - 每个epoch包含训练和验证两个阶段
   - 训练时使用DropPath进行随机深度正则化
   - 验证时计算准确率、AUC等指标（MedMNIST）或准确率、精确率、召回率、F1、AUC等（其他数据集）

3. **模型保存**: 
   - 保存最佳验证准确率对应的模型
   - 保存内容包括：模型权重、优化器状态、学习率调度器状态、准确率、epoch数

## 🌊 数据流

### 数据流向

#### 训练流程数据流
```
命令行参数
  ↓
args对象 (model_name, dataset, batch_size, lr, epochs等)
  ↓
build_dataset(args)
  ↓
train_dataset, test_dataset, nb_classes
  ↓
DataLoader (train_loader, test_loader)
  ↓
训练循环:
  images (B, 3, 224, 224) + labels (B,)
    ↓
  model.forward(images)
    ↓
  outputs (B, num_classes)
    ↓
  loss = criterion(outputs, labels)
    ↓
  loss.backward() → optimizer.step()
```

#### 模型前向传播数据流
```
输入: images (B, 3, 224, 224)
  ↓
Stem层:
  ConvBNReLU(3→64, stride=2) → (B, 64, 112, 112)
  ConvBNReLU(64→32, stride=1) → (B, 32, 112, 112)
  ConvBNReLU(32→64, stride=1) → (B, 64, 112, 112)
  ConvBNReLU(64→64, stride=2) → (B, 64, 56, 56)
  ↓
Stage 1: LFP块 × depths[0]
  (B, 64, 56, 56) → (B, dims[0], 56, 56)
  ↓
Stage 2: LFP块 × (depths[1]-1) + GFP块 × 1
  (B, dims[0], 56, 56) → (B, dims[1], 28, 28)
  ↓
Stage 3: [LFP, LFP, GFP] × (depths[2]//3)
  (B, dims[1], 28, 28) → (B, dims[2], 14, 14)
  ↓
Stage 4: GFP块 × depths[3]
  (B, dims[2], 14, 14) → (B, dims[3], 7, 7)
  ↓
BatchNorm2d → (B, dims[3], 7, 7)
  ↓
AdaptiveAvgPool2d(1, 1) → (B, dims[3], 1, 1)
  ↓
flatten → (B, dims[3])
  ↓
分类头 (Linear) → (B, num_classes)
  ↓
输出: logits (B, num_classes)
```

#### LFP块数据流
```
输入: x (B, C_in, H, W)
  ↓
PatchEmbed → (B, C_out, H', W')
  ↓
Norm1 → (B, C_out, H', W')
  ↓
reshape → (B, H'*W', C_out)
  ↓
NeighborhoodAttention → (B, H'*W', C_out)
  ↓
reshape → (B, C_out, H', W')
  ↓
残差连接 + DropPath → (B, C_out, H', W')
  ↓
Norm2 → (B, C_out, H', W')
  ↓
LocalityFeedForward → (B, C_out, H', W')
  ↓
残差连接 → (B, C_out, H', W')
```

#### GFP块数据流
```
输入: x (B, C_in, H, W)
  ↓
PatchEmbed → (B, C_mhsa, H', W')
  ↓
Norm1 → (B, C_mhsa, H', W')
  ↓
reshape → (B, H'*W', C_mhsa)
  ↓
E_MHSA → (B, H'*W', C_mhsa)
  ↓
reshape + 残差连接 → (B, C_mhsa, H', W')
  ↓
Projection → (B, C_mhca, H', W')
  ↓
MHCA + 残差连接 → (B, C_mhca, H', W')
  ↓
concat → (B, C_out, H', W')
  ↓
Norm2 → (B, C_out, H', W')
  ↓
KAN → (B, C_out, H', W')
  ↓
残差连接 → (B, C_out, H', W')
```

### 关键数据
- **输入图像**: (B, 3, 224, 224) - 批次大小B，RGB三通道，224×224分辨率
- **特征图**: 经过Stem和各Stage后，特征图尺寸逐步减小，通道数逐步增加
- **模型输出**: (B, num_classes) - 每个样本的类别logits
- **损失值**: 标量，用于反向传播和优化
- **评估指标**: 准确率、AUC、精确率、召回率、F1等
